## Notes

1. **Commas inside URLs (GramBeddings):** 3,197 train rows and 812 test rows contain commas in the URL field. Naive 2-field CSV parsing FAILS (pandas `ParserError: Expected 2 fields in line 126, saw 6`). Pipeline must split each line on the **first** comma only (e.g., `str.split(',', 1)`) or use single-column read + manual split.
2. **Label conflict on duplicate URL (GramBeddings train):** `http://sbcgloballoginz.com/` appears twice — once labeled 1 (Phish), once labeled 2 (Legitimate). Impact: exact-duplicate dedup by URL would be label-ambiguous; 1 row of 640,000 (0.00016%) — negligible but documented.
3. **No trailing newline** in GramBeddings CSVs — line-count-based verification must add 1.
4. PhreshPhish `url` min lengths (8 train / 5 test, e.g., `kit.com/`, `t.me/`) are short but well-formed registrable URLs; max 25,523 chars (train) may need truncation guards in downstream feature extraction.
5. Method: full-file manual line parsing for GramBeddings (no sampling); pyarrow `ParquetFile` full reads for PhreshPhish (1 row group each). Read-only audit; zero data modified.
